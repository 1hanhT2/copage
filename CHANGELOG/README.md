# Changelog

One file per **variant / release**. Each release gets a dated entry summarizing user-visible changes, bug fixes, technical notes, and verification.

---

## Format

```markdown
# vX.Y.Z — Title

**Date:** YYYY-MM-DD
**Base:** previous variant (or "initial")

## What changed
- Bullet list of user-visible features or updates

## Fixes
- Bullet list of resolved bugs or defects

## Technical notes
- Architecture, dependencies, migrations, gotchas

## Verification
- [ ] Verification steps and test commands
```
